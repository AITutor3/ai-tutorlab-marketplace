# AI튜터랩 마켓플레이스

사내 업무용 플러그인 모음입니다.

## 설치 방법 (Claude Code)

```
/plugin marketplace add AITutor3/ai-tutorlab-marketplace
/plugin install company-work-kit@ai-tutorlab-marketplace
```

## 포함된 플러그인

- **company-work-kit** – 보고서 작성, 회의록 정리, Google Docs 저장

## 새 플러그인 추가

`plugins/` 아래에 폴더를 추가하고 `.claude-plugin/marketplace.json`의 `plugins` 배열에 항목을 등록합니다.
