# 보고서 작성

사용자가 준 주제·자료로 사내 보고서를 작성하고 Google Docs에 저장한다.

## 절차

1. 부족한 정보만 확인한다: 보고 목적, 보고 대상(결재자), 기간/범위, 핵심 수치·자료, 분량. 이미 제공된 내용은 다시 묻지 않는다.
2. `references/report-structure.md`의 구조에 맞춰 초안을 작성한다.
3. 수치·날짜·고유명사는 제공된 자료에 있는 것만 쓴다. 자료에 없는 내용은 지어내지 말고 `[확인 필요]`로 표시한다.
4. Google Docs 커넥터로 문서를 생성해 저장한다. 제목은 `[보고서] {주제} ({YYYY-MM-DD})` 형식으로 한다.
5. 저장 후 문서 링크와 함께 `[확인 필요]` 항목 목록을 한두 문장으로 알린다.

## 문체 원칙

- 격식체(~합니다/~입니다)를 일관되게 쓴다. 개조식이 필요한 요약 부분은 명사형 종결(~함, ~임)로 통일한다.
- 결론을 먼저 쓰고 근거를 뒤에 둔다(두괄식).
- 한 문장은 한 가지 내용만 담고, 수치에는 단위와 기준 시점을 붙인다.
- 불필요한 수식어와 외래어 남발을 피한다.

## Google Docs 저장이 불가능할 때

커넥터가 연결되지 않았거나 실패하면 동일한 내용을 대화에 마크다운으로 제시하고, 커넥터 연결 후 다시 저장할 수 있다고 안내한다.
