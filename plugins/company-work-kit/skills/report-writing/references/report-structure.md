# 보고서 표준 구조

1. **제목** — 보고서명, 작성일, 작성자(부서), 보고 대상
2. **요약(핵심 결론)** — 3줄 이내. 결론과 요청 사항을 먼저 제시
3. **배경 및 목적** — 보고 배경, 현재 상황
4. **현황 / 주요 내용** — 사실·수치 중심. 필요 시 표 사용
5. **분석 및 시사점** — 원인, 비교(계획 대비, 전기 대비), 리스크
6. **향후 계획 / 건의 사항** — 실행 항목, 담당자, 일정
7. **첨부 / 참고** — 근거 자료, 출처

## 보고 유형별 가감

- 주간·월간 보고: 3~4번 중심, 5번은 이슈 위주로 간략히
- 결과 보고: 5번(성과 분석)을 강화
- 건의·품의성 보고: 6번(건의 사항)과 기대 효과를 강화
