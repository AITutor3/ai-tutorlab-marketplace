# 회의록 정리

사용자가 준 회의 메모·녹취·텍스트를 표준 회의록으로 정리해 Google Docs에 저장한다.

## 절차

1. 입력 자료(붙여넣은 텍스트, 첨부 파일)를 읽는다. 회의명, 일시, 장소, 참석자가 빠져 있으면 한 번에 묻는다. 모르면 `[확인 필요]`로 둔다.
2. `references/minutes-template.md` 구조로 정리한다.
3. 결정 사항과 액션 아이템을 반드시 분리해 추출한다. 액션 아이템에는 담당자와 기한을 붙이고, 원문에 없으면 `[담당 미정]`, `[기한 미정]`으로 표시한다.
4. 원문에 없는 발언·결정을 추가하지 않는다. 발언은 요지 중심으로 요약하되 의미를 바꾸지 않는다.
5. Google Docs 커넥터로 저장한다. 제목은 `[회의록] {회의명} ({YYYY-MM-DD})` 형식으로 한다.
6. 저장 후 문서 링크, 결정 사항 수, 액션 아이템 수를 한두 문장으로 알린다.

## 문체 원칙

- 개조식 명사형 종결(~함, ~임, ~예정)로 간결하게 쓴다.
- 안건별로 논의 → 결정 순서로 정리한다.

## Google Docs 저장이 불가능할 때

대화에 마크다운으로 회의록을 제시하고, 커넥터 연결 후 저장할 수 있다고 안내한다.
