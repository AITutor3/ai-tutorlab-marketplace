# company-work-kit

사내 업무용 통합 플러그인입니다.

## 구성

| 구분 | 이름 | 역할 |
|---|---|---|
| 스킬 | report-writing | 표준 구조·격식체 보고서 작성 후 Google Docs 저장 |
| 스킬 | meeting-minutes | 회의 메모를 회의록(결정 사항·액션 아이템 포함)으로 정리 후 저장 |
| 커넥터 | Google Docs | 완성된 문서를 Google Docs에 저장 |

## 사용 예

- "이번 주 업무 내용으로 주간 보고서 써줘"
- "아래 회의 메모로 회의록 정리해서 Docs에 저장해줘"

## 준비

Google Docs 커넥터를 연결해야 자동 저장이 됩니다. 연결되지 않으면 대화창에 결과를 보여줍니다.
